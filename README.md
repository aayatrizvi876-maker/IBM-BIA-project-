## Run locally
Install:
`pip install pandas matplotlib seaborn jupyter`

Keep the notebook, script, and CSV in the same folder. Open the notebook in Jupyter and run cells from top to bottom, or run `python Netflix_Data_Analysis.py`.

## Dataset transparency
The bundled data is synthetic and created for demonstration. It is not Netflix's real catalog. Replace it with a sourced dataset if your instructor requires real-world data, and rerun the analysis before submission.
